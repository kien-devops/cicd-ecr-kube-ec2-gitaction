# Ansible Worker Bootstrap

This folder contains the Ansible flow used to prepare a new EC2 worker and join it to the Kubernetes cluster.

## Files

| File | Purpose |
|---|---|
| `provision-ec2-and-run-ansible.sh` | Full scale-out flow: Terraform add node, Ansible join, wait for Traefik, reload HAProxy. |
| `join_k8s.yml` | Ansible playbook for installing runtime packages and joining Kubernetes. |
| `common.sh` | Shared shell helpers. |
| `.env.example` | Example environment file. |
| `hosts.ini` | Generated by Terraform. Not meant to be edited by hand. |
| `kien.pem` | EC2 SSH key. Keep local only. |

## Required Local Files

Create the env file:

```bash
cd ansible-web
cp .env.example .env
```

Set a fresh join command from the Kubernetes control plane:

```bash
kubeadm token create --print-join-command
```

Put it in `.env`:

```env
KUBEADM_JOIN_COMMAND="kubeadm join <control-plane-ip>:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>"
```

Make sure the SSH key exists:

```bash
chmod 400 kien.pem
```

## Run Full Scale-Out

```bash
cd ansible-web
bash provision-ec2-and-run-ansible.sh
```

The script does this:

1. Runs `terraform/add-node.sh`.
2. Reads Terraform outputs and generated `hosts.ini`.
3. Runs `ansible-playbook -i hosts.ini join_k8s.yml`.
4. Waits until the new Kubernetes node is Ready.
5. Waits for Traefik DaemonSet on the new node.
6. Reloads HAProxy backend config.

## Run Only Ansible

Use this only when Terraform already created `hosts.ini`:

```bash
cd ansible-web
ansible-playbook -i hosts.ini join_k8s.yml
```

## Verify

```bash
kubectl get nodes -o wide
kubectl get pods -n traefik -o wide
```
